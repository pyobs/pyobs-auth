# specs/

This repo keeps its own implementation plans under `plans/` (see `plans/index.md`). Design docs
and ADRs that concern `pyobs-auth` live in `pyobs-core`'s `specs/` tree instead (`specs/design/`,
`specs/plans/`, `specs/adrs/`), each tagged with a `Repos:` line naming every repo it concerns —
see `pyobs-core/CLAUDE.md`'s "Cross-repo docs" section.
